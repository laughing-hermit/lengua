# build

Not ready yet. At milestone L9 this skill will turn `idea.md` into Rust in `src/`: one file per
module idea, no comments, every function named in the idea's `# Structure`, and the standard
library first. Then it calls the MCP tool `check`. The design is in `Lengua3.md`, sections 4
and 5.
