# Programs

* [absdiff](absdiff/idea.md) - Prints the absolute difference of two whole numbers given as arguments. Code: [main.s](absdiff/main.s)
* [add](add/idea.md) - Adds two whole numbers given as arguments and prints the sum. Code: [main.s](add/main.s)
* [aes](aes/idea.md) - Encrypts blocks of hexadecimal data with AES-128 in ECB mode, using the CPU's AES instructions. Code: [main.s](aes/main.s)
* [archive](archive/idea.md) - Moves a file into the archive folder, making the folder when it's missing. Code: [main.s](archive/main.s)
* [count](count/idea.md) - Counts the lines and words of standard input and prints both, like wc -lw. Code: [main.s](count/main.s)
* [dice](dice/idea.md) - Rolls a fair six-sided die and prints the roll. Code: [main.s](dice/main.s)
* [echo](echo/idea.md) - A line-echo server that sends each connection's line back. Code: [main.s](echo/main.s)
* [fetch](fetch/idea.md) - Fetches a page from the web server on this computer's port 8080 and prints its body. Code: [main.s](fetch/main.s)
* [greet](greet/idea.md) - Greets whoever the NAME environment variable names. Code: [main.s](greet/main.s)
* [hypotenuse](hypotenuse/idea.md) - Prints the length of a right triangle's hypotenuse from its two side lengths, with three decimals. Code: [main.s](hypotenuse/main.s)
* [mean](mean/idea.md) - Prints the mean of two decimal numbers given as arguments, with two decimal places. Code: [main.s](mean/main.s)
* [sha256](sha256/idea.md) - Prints the SHA-256 digest of standard input. Code: [main.s](sha256/main.s)
* [sort](sort/idea.md) - Sorts the lines of standard input in byte order, optionally dropping duplicate lines. Code: [main.s](sort/main.s)
* [upcase](upcase/idea.md) - Copies a text file to another file with its ASCII letters in capitals. Code: [main.s](upcase/main.s)
