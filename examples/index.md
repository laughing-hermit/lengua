# Programs

* [absdiff](absdiff/idea.md) - Prints the absolute difference of the two whole numbers in its arguments. Code: [main.wat](absdiff/main.wat)
* [add](add/idea.md) - Adds the two whole numbers in its arguments and prints the sum. Code: [main.wat](add/main.wat)
* [aes](aes/idea.md) - Encrypts blocks of hexadecimal data with AES-128 in ECB mode, in portable code. Code: [main.wat](aes/main.wat)
* [archive](archive/idea.md) - Moves a file into the archive folder and makes the folder if it does not exist. Code: [main.wat](archive/main.wat)
* [computer](computer/idea.md) - Prints the name of the computer and the name of its user, which two programs of the computer give. Code: [main.wat](computer/main.wat)
* [copy](copy/idea.md) - Copies the file that its first argument names to the file that its second argument names. Code: [main.wat](copy/main.wat)
* [count](count/idea.md) - Counts the lines and words of standard input and prints the two counts, as wc -lw does. Code: [main.wat](count/main.wat)
* [dice](dice/idea.md) - Rolls a fair six-sided die and prints the roll. Code: [main.wat](dice/main.wat)
* [echo](echo/idea.md) - A server that sends each line back to the client that sent it. Code: [main.wat](echo/main.wat)
* [fetch](fetch/idea.md) - Gets a page from the web server on port 8080 of this computer and prints its body. Code: [main.wat](fetch/main.wat)
* [follow](follow/idea.md) - Gets a page from a web server of example.org and follows one redirect to another of its web servers. Code: [main.wat](follow/main.wat)
* [greet](greet/idea.md) - Greets the person that the NAME environment variable names. Code: [main.wat](greet/main.wat)
* [histogram-split](histogram-split/idea.md) - Counts how many times each byte value occurs in standard input, with the work split into pieces that run at once. Code: [main.wat](histogram-split/main.wat)
* [hypotenuse](hypotenuse/idea.md) - Prints the length of the hypotenuse of a right triangle from the lengths of its two sides, with three decimals. Code: [main.wat](hypotenuse/main.wat)
* [key](key/idea.md) - Waits until a person presses a key, and reads the key from the terminal without the Enter key. Code: [main.wat](key/main.wat)
* [mean](mean/idea.md) - Prints the mean of the two decimal numbers in its arguments, with two decimal places. Code: [main.wat](mean/main.wat)
* [secret-equal](secret-equal/idea.md) - Prints same if the two lines of its input are the same and diff if not, with no branch on their bytes. Code: [main.wat](secret-equal/main.wat)
* [sha256](sha256/idea.md) - Prints the SHA-256 digest of standard input. Code: [main.wat](sha256/main.wat)
* [sort](sort/idea.md) - Sorts the lines of standard input in byte order and can drop duplicate lines. Code: [main.wat](sort/main.wat)
* [upcase](upcase/idea.md) - Copies a text file to another file with its ASCII letters in capitals. Code: [main.wat](upcase/main.wat)
