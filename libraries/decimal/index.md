# Where it runs

* A lengua library, built into each program that uses it, as WebAssembly. It reaches nothing of its own.

# Back end: program

* [decimal](idea.md) - The library reads and writes whole numbers and decimal numbers with a fixed number of places, as `i64` values. Label: `checked`.

# Back end: crates

* Declared in the ideas: none; the code uses the Rust standard library alone.
