# Libraries

* [ai](ai/index.md) - The library helps a program that asks an AI model. Label: `checked`. Used by: [ask](../examples/ask/index.md).
* [dates](dates/index.md) - The library works with civil dates of the Gregorian calendar and with times in UTC. Label: `checked`.
* [decimal](decimal/index.md) - The library reads and writes whole numbers and decimal numbers with a fixed number of places, as `i64` values. Label: `checked`. Used by: [prices](../examples/prices/index.md), [shop](../examples/shop/index.md).
* [hashes](hashes/index.md) - The library gives the SHA - 256 hash and the CRC - 32 value of bytes. Label: `checked`. Used by: [logins](logins/index.md).
* [http](http/index.md) - The library reads and writes the messages of HTTP / 1.1, as RFC 9112 gives them. Label: `checked`.
* [json](json/index.md) - The library reads and writes JSON text, as RFC 8259 gives it, with a value type of its own. Label: `checked`. Used by: [desk](../examples/desk/index.md), [shop](../examples/shop/index.md), [ai](ai/index.md), [vectors](vectors/index.md).
* [logins](logins/index.md) - The library keeps the logins of a program. Label: `checked`. Used by: [notes](../examples/notes/index.md).
* [sort](sort/index.md) - The library sorts a list in a stable order and finds a value in a sorted list. Label: `checked`.
* [text](text/index.md) - The library cuts text into lines, parts and words. Label: `checked`.
* [vectors](vectors/index.md) - The library finds the texts that are near to a question by their vectors. Label: `checked`. Used by: [ask](../examples/ask/index.md).
