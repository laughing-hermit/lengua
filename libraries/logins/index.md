# Where it runs

* A lengua library, built into each program that uses it, as WebAssembly. It reaches nothing of its own.

# Back end: program

* [logins](idea.md) - The library keeps the logins of a program. Label: `checked`.

# Back end: libraries

* [hashes](../hashes/idea.md) - The library gives the SHA - 256 hash and the CRC - 32 value of bytes. Label: `checked`.

# Back end: crates

* Declared in the ideas: none; the code uses the Rust standard library alone.
